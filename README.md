# dotfiles-devpod
Configuration compatible with [DevPod](https://github.com/loft-sh/devpod) dotfiles with:
* Full nvim setup + tmux
* oh-my-bash with agnoster theme

## Usage
Execute `run-dev.sh <devcontainer json file>` from any directory to create dev-env using DevPod with nvim, tmux and basic tools for development.
